## Root cause (source-verified)

- `drivers/opp/core.c` `_opp_supported_by_regulators()`: an OPP whose
  `opp-microvolt` is not on the regulator's supported voltage grid is
  marked unavailable.
- pm8005_s1 = SPMI ftsmps426: step 4000 uV (4 mV). 965000/4000 =
  241.25 → off-grid → rejected.
- All stock measured voltages (936/908/856/792/704/644/628) are
  exactly on-grid (÷4 integer) — the stock table was accepted.

## Fixed/decided

- Fix committed `92df37a6a` (same branch): `opp-microvolt` 965000 →
  964000 (on-grid: 964/4=241; matches ~0.7 mV/MHz extrapolation from

- The 750 MHz clock-chain question remains OPEN — the PLL/RCG was
  never asked for 750. Not a silicon rejection.
