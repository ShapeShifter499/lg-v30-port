### Decisions

- The Card 94 SMMU/XPU2 mechanism and the A540 SP/TP/RBCCU collapse failure are
  separate mechanisms. This boot supports retaining the SMMU fix while
  investigating the GPU callback independently.
- Absence of a reset is a scoped pass; it is not power-cycle closure.
- No workload may run when idle runtime PM is already in `error`.
- Source review corrected an early hypothesis: mainline already writes the
  same four GPMU inter-frame collapse registers as downstream through
  `a5xx_power_init()`. The next diagnostic must read back GPMU init/status and
  those registers rather than adding duplicate programming blindly.
