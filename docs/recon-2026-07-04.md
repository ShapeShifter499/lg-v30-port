# LG V30 (joan, US998) mainline Linux port — recon report

**Goal:** boot a modern mainline kernel (6.x) on Lance's LG V30 US998, postmarketOS as the
first userspace target, AOSP-on-mainline as the stretch goal. Daily driver remains
LineageOS 22.2 (Android 15, downstream kernel 4.4) — install that first; the port uses
tethered/recovery-slot boots and never touches the LineageOS install.

## Prior art — nobody has done this yet

- **No pmOS port exists**: no `device-lg-joan` in pmaports (master), no merge requests
  mentioning joan or V30, no `lg-joan` code anywhere on GitHub.
- XDA "LG V30 Linux" thread (4455413): people wanting Linux on the V30 were pointed at
  LG's downstream kernel — confirms prior "attempts" were downstream/Halium-style, not
  mainline.
- We would be first movers for this device — but **not** for the SoC (see below).

## SoC groundwork is strong (msm8998 in mainline)

Mainline `arch/arm64/boot/dts/qcom/` already has 9+ msm8998 boards:

- Phones: **OnePlus 5/5T** (cheeseburger/dumpling), **Sony Xperia XZ1 family**
  (yoshino: lilac/maple/poplar), **F(x)tec Pro1**, Xiaomi Mi 6 (sagit)
- Laptops: Asus NovaGo, HP Envy x2, Lenovo Miix 630, plus MTP reference board

So CPU, UFS storage, USB, Adreno 540 (freedreno), WiFi (ath10k/WCN3990 SNOC), Venus
video, GPIO/regulators are solved at SoC level. postmarketOS ships a shared
**`linux-postmarketos-qcom-msm8998`** kernel package (6.x) used by OnePlus 5/5T — the
natural vehicle for a joan port. Reference repos: JamiKettunen's (archived, merged
upstream) `linux-mainline-oneplus5` + `firmware-mainline-oneplus5`.

## joan hardware inventory (from downstream lineage-22.2 kernel)

Downstream tree cloned at `~/vibe-coding-projects/coding/android_kernel_lge_msm8998`
(branch lineage-22.2, LG DTS under `arch/arm64/boot/dts/lge/msm8998-joan/`,
defconfig `lineageos_joan_defconfig`; US998 board files = `joan_nao_us` /
`joan_acg_us` variants — confirm exact rev from running device).

| Subsystem | Hardware | Mainline outlook |
|---|---|---|
| Panel | LG **SW43402** P-OLED, QHD, DSI command mode **with DSC** (sw43401 on early revs) | ⚠️ **Biggest risk.** msm8998 display = MDP5 in mainline, which has **no DSC support** (DSC landed for DPU/sdm845+ only). Options: check panel for uncompressed lower-res mode, port DSC to MDP5 (hard), or run headless-with-USB first. |
| Touch | STM **FTM4** (fts) | ✅ mainline `stmfts` driver exists, used by Xperia yoshino — likely small DT + maybe quirks |
| Storage | UFS | ✅ solved on msm8998 |
| USB | dwc3 | ✅ solved; gadget mode = first debug channel |
| GPU | Adreno 540 | ✅ freedreno, proven on OP5/yoshino |
| WiFi/BT | WCN3990-class (SNOC) | ✅ ath10k + firmware from device; BT likely wcn3990 serdev |
| Audio | WCD9341 codec + **ES9218** quad-DAC (i2c@48) | ⚠️ WCD9341 partial in mainline; ES9218 has **no mainline driver** — speaker/headset maybe, quad-DAC = write a codec driver (long tail) |
| Camera | LG camera stack on CAMSS | ❌ realistically never (ISP userspace) |
| Modem | msm8998 MPSS | ❓ maybe — works on yoshino-class devices to varying degrees |
| Sensors | joan-sensor.dtsi (SSC/DSP-attached) | ❓ late-stage |

## Boot/test loop

- US998 unlocks via plain `fastboot oem unlock` (bootloader unlock = step zero, wipes device).
- **Verify whether LG aboot supports `fastboot boot` (tethered boot)** — ten-second test,
  historically missing on LG. Fallback: use the **recovery partition as the test slot**
  (`fastboot flash recovery`, key-combo boot); LineageOS + boot partition stay untouched.
- Feedback channels from iteration one: pstore/ramoops (read panic logs after reboot to
  Android) + USB gadget (RNDIS/serial). Milestone 1 = device enumerates in `lsusb`.
- LineageOS 22.2 install prerequisite: stock **Android 9 (Pie)** US998 firmware baseline.

## Chunk plan

1. ~~Recon~~ (this report)

4. Boot-to-lsusb loop until proof of life
5. Touch (stmfts) + WiFi (ath10k + firmware extraction from device)
6. Display spike: SW43402 panel driver skeleton + DSC feasibility verdict on MDP5
7. pmOS device package (`device-lg-joan`) once bootable → upstream to pmaports
8. Stretch: GPU/audio/sensors; AOSP-on-mainline experiment
